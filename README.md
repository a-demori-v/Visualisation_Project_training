# Power BI – Data Visualization Project

Ce dépôt regroupe mes travaux pratiques et exercices réalisés dans le cadre de mon apprentissage de **Microsoft Power BI**.

L'objectif est de découvrir les fonctionnalités de Power BI et de développer mes compétences en analyse et visualisation de données.

## Objectifs d'apprentissage

- Importer et préparer des jeux de données.
- Explorer et analyser les données.
- Créer des visualisations pertinentes.
- Concevoir des tableaux de bord interactifs.
- Découvrir les fonctionnalités de Power Query et du langage DAX.

## Outils utilisés

- Microsoft Power BI
- Power Query
- DAX (en cours d'apprentissage)

## Avancement

Projet personnel en cours, enrichi progressivement au fil de mon apprentissage.
